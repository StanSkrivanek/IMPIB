# Security policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, exploit details, private data, or sensitive screenshots in a public issue.

Use this repository's **Security** tab and **Report a vulnerability** option when it is available. That creates a private report visible only to the repository maintainers. If the private form is unavailable, open a minimal issue asking the maintainer to provide a private contact method. Do not include technical details in that issue.

Include the affected IMPIB page or feature, browser and operating system, impact, and safe reproduction steps in the private report. Do not include confidential images or metadata.

General bugs, feature requests, and documentation feedback should use the public [issue forms](https://github.com/StanSkrivanek/IMPIB/issues/new/choose).
