# IMPIB support

This repository is the public support and feedback space for [IMPIB](https://www.impib.dev). The application source and internal development repository are private.

## Before opening an issue

1. Check the [existing issues](https://github.com/StanSkrivanek/IMPIB/issues) for the same problem or request.
2. Confirm the problem still happens after refreshing IMPIB and trying the latest version of your browser.
3. Choose the appropriate [issue form](https://github.com/StanSkrivanek/IMPIB/issues/new/choose).

For a bug, include:

- the browser, browser version, operating system, and device;
- the source image format and pixel dimensions;
- the selected output formats, sizes, templates, and relevant settings;
- clear steps to reproduce the problem;
- what you expected and what happened instead.

## Protect your images and data

Do not attach confidential source images, exported files, filenames, or metadata. Reproduce the problem with a safe sample image whenever possible. Screenshots should be cropped or redacted so they contain no personal, customer, or commercially sensitive information.

## Scope

GitHub Issues may be used for reproducible bugs, accessibility problems, documentation corrections, and focused feature requests. Please keep one problem or request per issue.

Potential security vulnerabilities do not belong in public Issues. Follow [SECURITY.md](SECURITY.md) instead.
